Private GitHub Actions · Android

ZIP → APK

Upload een Android-project. De builder installeert de workflow, analyseert het project en bouwt automatisch een APK in je privérepository.

1 · Privérepository koppelen

Benodigd: alleen deze repository geselecteerd, met Contents: Read/Write, Workflows: Read/Write en Actions: Read. De token wordt niet opgeslagen en gaat rechtstreeks van Firefox naar api.github.com.

De repository wordt gecontroleerd op privéstatus en schrijfrechten voordat er iets wordt geüpload.

2 · Android-project uploaden

Maximaal 35 MB per ZIP. De ZIP wordt tijdelijk in je privérepository gezet en na een geslaagde build verwijderd.
