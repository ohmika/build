Now on GitHub

  1. Open your repository, then Add file → Upload files, pick the zip you just downloaded and commit. Keep only one zip in the repository: the newest one is used.
  2. Once per repository: upload build.yml the same way, open it, tap the pencil and change the file name to .github/workflows/build.yml, then commit. Replace the old workflow if there is one.
  3. For a stable signing identity, create the repository secret ANDROID_DEBUG_KEYSTORE_BASE64 containing the Base64-encoded contents of your own debug keystore. Keep the keystore private and back it up.
  4. Open the Actions tab. A green check means it worked (build time varies by project).
  5. Open Releases and tap the APK to download it.
  6. Red cross? Open the run, copy the red lines and send them to Claude.
